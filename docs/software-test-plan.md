# MiniObsidian 软件测试文档

## 1. 文档概述

### 1.1 文档目的
本文档为 MiniObsidian 桌面应用提供全面的测试规范，涵盖功能测试、兼容性测试、压力测试和闪退稳定性测试，确保软件质量达到发布标准。

### 1.2 测试范围
- 核心笔记管理功能
- PDF 文件处理功能
- AI 问答功能
- 笔记拖拽移动功能
- 搜索与图谱功能
- 同步功能
- 日志与错误上报系统

### 1.3 测试环境
| 环境项 | 配置要求 |
|--------|----------|
| 操作系统 | Windows 10/11 (64-bit) |
| 内存 | >= 8GB RAM |
| 存储 | >= 2GB 可用空间 |
| 分辨率 | 1920x1080, 1366x768, 2560x1440 |
| 浏览器引擎 | Tauri WebView2 |

---

## 2. 缺陷分级标准

| 级别 | 定义 | 处理要求 |
|------|------|----------|
| **P0-致命** | 应用崩溃、数据丢失、无法启动 | 立即修复，阻断发布 |
| **P1-严重** | 核心功能不可用、界面白屏 | 24小时内修复 |
| **P2-一般** | 功能异常但有替代方案 | 3天内修复 |
| **P3-轻微** | 界面显示问题、体验不佳 | 下个版本修复 |
| **P4-建议** | 优化建议、功能增强 | 评估后排期 |

## 9. 测试工具与方法

### 9.1 自动化测试
- Rust 单元测试：`cargo test`
- 前端类型检查：`npm run typecheck`
- 构建验证：`npx tauri build`

### 9.2 手动测试
- 功能测试：按用例手动执行

- 日志位置：`%APPDATA%/mini-obsidian/logs/`
- 错误过滤：搜索 `ERROR` 关键字
- 堆栈分析：查看 `stack` 字段
